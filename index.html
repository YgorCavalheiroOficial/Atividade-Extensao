🛡️ Dicas de Segurança

Antes de compartilhar uma publicação:

  • ✓ Verifique quem publicou.
  • ✓ Confira a data.
  • ✓ Desconfie de promessas de dinheiro fácil.
  • ✓ Nunca forneça senhas ou códigos.
  • ✓ Não clique em links suspeitos.
  • ✓ Confirme a informação em fontes oficiais.
  • ✓ Desconfie de mensagens com urgência.
  • ✓ Observe imagens e vídeos com atenção.

🔎 Como identificar um possível golpe?

  1. Promessa boa demais.
  2. Pressa para tomar uma decisão.
  3. Pedido de dados pessoais.
  4. Pedido de pagamento.
  5. Link desconhecido.
  6. Perfil ou página suspeita.
